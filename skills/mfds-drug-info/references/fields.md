## 2. 날짜 형식이 둘이다 🔴

```
openDe    "20210129"     하이픈 없음 (8자)
updateDe  "2024-05-09"   하이픈 있음 (10자)
```

같은 레코드 안에서 형식이 다르다. 래퍼가 파생 필드로 통일한다(§5).
**원본 필드끼리 비교하거나 정렬하지 말 것.**

## 3. 🔴 `updateDe` 검색은 8자까지만 동작한다

**API 검색과 실제 데이터가 어긋나는 지점이다.** 로컬 전수 집계와 대조한 결과:

| 보낸 값 | 길이 | API `totalCount` | 로컬 prefix 집계 | |
|---|---|---|---|---|
| `2021` | 4자 | 1,931 | 1,931 | ✅ 일치 |
| `2021-0` | 6자 | 1,299 | 1,299 | ✅ 일치 |
| `2021-01` | 7자 | 1,157 | 1,157 | ✅ 일치 |
| `2021-01-` | 8자 | 1,157 | 1,157 | ✅ 일치 |
| `2021-01-2` | 9자 | **0** | 1,157 | 🔴 불일치 |
| `2021-01-29` | 10자 | **0** | 1,157 | 🔴 불일치 |
| `2024-05-09` | 10자 | **0** | 1 | 🔴 불일치 |

**8자까지는 앞자리 일치로 정확히 동작하고, 9자부터는 무조건 0건이다.**
경계가 정확히 8/9자에서 갈리는 것을 서로 다른 날짜 3개로 재현했다.

응답에 `2024-05-09`로 오는 값을 그대로 검색하면 0건이 나온다는 뜻이다.
래퍼가 전송 전에 막는다. 하루 단위가 필요하면 전수로 받아 `_updateDate`로 거른다.

`openDe`는 반대로 `YYYYMMDD`(하이픈 없음)라야 한다 — `2021-01-29`는 0건이다.

## 4. 🔴 행 유일 키는 `itemSeq` 하나가 아니다

전수 4,775행 / 고유 `itemSeq` **4,758개** / 중복 `itemSeq` **14개**.

**14개 그룹 전부에서 달라지는 필드가 `itemImage` 하나뿐이다**(나머지 13개 필드 동일).
낱알 이미지가 여러 장인 약이 행으로 쪼개져 나온다.

```
197100015 x2  198701352 x3  200502139 x2  200700800 x2  200806190 x2
200806191 x2  200806192 x2  201205838 x2  201208419 x3  201507772 x2
201902565 x3  202001726 x2  202100082 x2  202501737 x2
```

`(itemSeq, itemName)` 조합도 유일 키가 **아니다**(같은 14개가 그대로 중복).

> 래퍼는 기본으로 `itemSeq` 기준 병합하고 이미지를 `_itemImages`에 모은다.
> **4,775행 → 4,758건 / 합친 행 17건**으로, 위 집계와 정확히 맞는다.
> 정보 손실이 없으므로 기본값으로 뒀다. 원본이 필요하면 `--no-merge`.

## 5. 파생 필드 (래퍼가 계산)

`_`로 시작하는 것은 **API가 준 값이 아니다.**

| 필드 | 계산 |
|---|---|
| `_openDate` | `openDe`(`20210129`) → `2021-01-29` |
| `_updateDate` | `updateDe` 그대로(이미 `YYYY-MM-DD`). 두 날짜를 같은 형식으로 쓰기 위한 것 |
| `_itemImages` | 병합된 같은 `itemSeq` 행들의 `itemImage` 배열 |
| `_imageCount` | 위 배열 길이 |
| `_hasImage` | 이미지가 하나라도 있으면 `true` |
| `_truncated` | `--truncate-text`로 잘린 필드명 배열 (자른 행에만) |

`--fields`나 `--preset`으로 걸러도 파생 필드는 항상 남는다.

## 7. 봉투

```json
{
  "header": {"resultCode": "00", "resultMsg": "NORMAL SERVICE."},
  "body": {"pageNo": 1, "totalCount": 4775, "numOfRows": 2, "items": [ ... ]}
}
```

- **`response` 래퍼가 없다.** 최상위가 곧 `header`/`body` (실거래가와 같음)
- **정상 `resultCode`는 `"00"`(2자리)다.** 실거래가는 `"000"`(3자리)
- `numOfRows` 상한 **500**. 넘기면 `code 11`인데 메시지가
  `NO MANDATORY REQUEST PARAMETERS ERROR!`라 원인을 오해하기 쉽다.
  뒤쪽에 `numOfRows maximum is =[500]`이 붙어 있다
- `pageNo`를 넘겨도(9999) 에러가 아니라 `items` 빈 배열이다

### `type=json` 유무로 봉투가 바뀐다 🔴

| | `type=json` | 생략 |
|---|---|---|
| `items` | 배열 (1건이어도 `list`) | `{"item": {...}}` — 1건이면 `dict` |
| 빈 값 | `null` | `""` |
| `pageNo`·`totalCount` | 숫자 | 문자열 |

래퍼는 항상 `type=json`을 붙인다.
